What is Medical Image Segmentation?

Given a 3D CT or MRI scan (up to 512 × 512 × 500 voxels), automatically delineate the precise 3D boundary of target structures — organs, lesions, or anatomical landmarks — producing a binary volumetric mask.

Manual segmentation by a trained radiologist takes 20–30 min per organ. Automated segmentation enables scalable clinical workflows and reproducible research.

Our Task

Speed up two segmentation models without degrading accuracy. Every optimization must be verified against ground truth.

VoxTell — Fix 1: FP16 GPU Placement

05 / 12
Root Cause

FP32 (32-bit precision) Qwen3 requires ~16GB VRAM. The RTX 4070 SUPER has 12GB. PyTorch performs no error — it silently moves the model to CPU and runs at CPU speed.

Fix
# Before — FP32, silently CPU-bound model = AutoModel.from_pretrained( "Qwen/Qwen3-Embedding-4B" ) # After — FP16, stays on GPU model = AutoModel.from_pretrained( "Qwen/Qwen3-Embedding-4B", dtype=torch.float16 ) model = model.to(device)

FP16 is safe for embedding extraction — embeddings are direction vectors (cosine similarity), not absolute magnitudes. DSC unchanged within 0.001.

nnInteractive — torch.compile Optimization

09 / 12
What is torch.compile?

PyTorch normally interprets the model graph at runtime — Python overhead on every forward pass. torch.compile traces the full computation graph and compiles it to optimized Triton GPU kernels via the inductor backend.

With mode='reduce-overhead', CUDA graphs are used to eliminate CPU-to-GPU launch latency on repeated calls with identical input shapes — which is exactly the nnInteractive inference pattern.

Implementation
# One line after session initialization session.network = torch.compile( session.network, mode='reduce-overhead' )
Key Considerations
  • Triton cold start: ~24s — first call compiles Triton kernels. Cached to disk via XDG_CACHE_HOME. Subsequent jobs skip this. Break-even: ~321 objects (~22 cases).
  • N_WARMUP = 2 required — warmup 1 triggers Triton compilation (~24s); warmup 2 stabilizes dispatch (~0.51s). Runs 3+ are fully warm at 0.215s production average.
  • FP differences expected — Triton and cuDNN have different FP16 operation ordering. Non-associativity means compiled outputs are not bit-identical to baseline. DSC verification is mandatory.
  • fold='all' required — the official checkpoint (single model trained on full training set, DSC ~0.79). fold=0 gives ~0.33 DSC and is not a valid baseline for comparison.
